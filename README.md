# 杭州相亲帮帮 · 群组匹配工具

面向「杭州相亲帮帮群」的轻量 H5 匹配工具。零服务器，数据存本地，群里互相填资料 + 颜值自评 + 每日随机推荐 5 个符合条件的群友。

## 快速开始

- **直接使用**：打开 [在线版](https://huangkanyang.github.io/xiangqinbangbang/)（GitHub Pages 部署后生效）
- **本地使用**：下载 `相亲帮帮.html`，用浏览器打开即可

## 功能

- 📝 资料填写：昵称、性别、年龄、身高、老家（江浙沪为主）、照片链接
- 💯 颜值自评：10 道题（2/6/10 三档），自动算出 1-10 分
- 🎯 择偶要求：性别 / 年龄范围 / 身高范围 / 老家 / 颜值分下限
- 💘 每日 5 个推荐：自动筛选 + 随机抽取，每天 0 点重置
- 👑 群主模式：合并群友资料 JSON，一键导出全群数据

## 使用流程

1. 填写资料 + 颜值自评
2. 点「复制我的资料」发到群里
3. 群主合并后发回群文件
4. 用户「导入群数据」→ 看每日推荐

详见 [使用说明](./使用说明.md) 和 [部署说明](./部署说明.md)。

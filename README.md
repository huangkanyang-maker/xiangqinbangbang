# 杭州相亲帮帮 · 群组匹配工具

面向「杭州相亲帮帮群」的轻量 H5 匹配工具。上传照片 → AI 客观颜值打分 → 每日随机推荐 5 个符合条件的群友。

## 快速开始

- **在线版**：https://huangkanyang-maker.github.io/xiangqinbangbang/
- **本地版**：下载 `相亲帮帮.html` 用浏览器打开

## 功能

- 📝 资料填写：昵称、性别、年龄、身高、老家（全国 34 省级行政区）、照片
- 📱 联系方式：抖音 / 小红书 / 微信（选一种填账号）
- 🤖 AI 颜值打分：上传照片，系统调用百度 AI 人脸检测客观评分（非自评）
- 🎯 择偶要求：性别 / 年龄 / 身高 / 老家（全国多选）/ 颜值分下限
- 💘 每日 5 个推荐：自动筛选 + 随机抽取，每天 0 点重置
- 🔒 权限隔离：群数据管理（合并/导出/清空/查看）仅群主密码可见，普通成员看不到

## 使用流程

1. 填资料 + 上传照片
2. AI 系统打分（客观颜值分，重评限 3 次）
3. 复制资料发到群里
4. 群主合并后导入群数据
5. 每天看 5 个推荐

## 群主须知

- 首次进入「我的 → 群主管理入口」需**设置群主密码**
- 「群主模式」里：合并群友资料、导出全群 JSON、清空数据、查看所有人
- **AI 打分需先配置百度 AI 接口**，见 [百度AI申请教程](./百度AI申请教程.md)
